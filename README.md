# 2026 雙北端午龍舟賽程查詢

> ※ 本頁資訊僅供查詢參考，實際賽程、成績、晉級名單與異動，仍以大會現場公告為準。

---

## 專案說明

本專案整理 **2026 年台北市與新北市端午龍舟賽事**資訊，方便選手、隊伍成員與觀賽者快速查詢比賽時間、城市、競賽類別、組別、水道、成績與晉級狀態。

本工具涵蓋以下兩場官方賽事：

- 🏆 **2026 臺北國際龍舟錦標賽**（台北市）
- 🏆 **新北市議長盃第十六屆龍舟錦標賽**（新北市）

---

## 功能特色

| 功能 | 說明 |
|------|------|
| 城市篩選 | 支援台北市 / 新北市賽事切換 |
| 龍舟類別 | 大型龍舟 / 小型龍舟篩選 |
| 組別篩選 | 男子組、女子組、混合組 |
| 日期篩選 | 依比賽日期快速篩選 |
| 模糊搜尋 | 支援隊名、場次、組別關鍵字搜尋 |
| 手機友善 | 卡片式介面，適合比賽現場查看 |
| 水道資訊 | 顯示各水道隊伍、成績、名次 |
| 晉級狀態 | 即時顯示晉級與淘汰資訊 |
| 比賽狀態 | 未開始 / 比賽中 / 已完成 / 延賽 / 取消 |

## 技術架構

本專案採用純前端靜態網頁架構，無需後端伺服器。

```
技術棧：
├── HTML          — 頁面結構
├── CSS           — 樣式設計（手機優先，內嵌於 index.html）
├── JavaScript    — 互動邏輯 / 資料篩選（內嵌於 index.html）
├── Google Sheet  — 資料管理（CSV 發布）
└── GitHub Pages  — 靜態網站部署
```

### 資料流程

```text
[ 大會更新 Google Sheet ]
         ↓
[ 發布成 CSV（公開存取）]
         ↓
[ GitHub Pages 前台頁面 ]
         ↓
[ JavaScript fetch 讀取 CSV ]
         ↓
[ 使用者查詢賽程 ]
```

## 本地開發

直接開啟 `index.html` 即可，無需任何安裝或建置步驟。

```bash
# 若需要本地伺服器（避免 CORS 問題）
npx serve .

# 或使用 Python
python3 -m http.server 8080
```

## Google Sheet 設定方式

1. 建立 Google Sheet，欄位依序設定（見下方欄位說明）
2. 選擇「檔案 → 共用 → 發布到網路」
3. 選擇「CSV」格式發布
4. 複製發布連結，填入 `index.html` 的 `SHEET_CSV_URL` 變數

## 部署（GitHub Pages）

1. 將程式碼推送到 GitHub Repository
2. 進入 `Settings → Pages`
3. 選擇 `main` 分支 → `/ (root)` 目錄
4. 儲存後等待部署完成
5. 網址格式：`https://{your-username}.github.io/dragonboat-2026/`
